Privacy Policy

Smart Task Manager · Last updated November 6, 2026

What it is

Smart Task Manager is a personal productivity tool that builds a to-do list from a user's own course calendar, email and Google Sheets. It is currently used by its developer and a small beta group.

What data it accesses

  • Gmail (read-only): to find emails that need a reply or contain deadlines. It cannot send, delete or change email.
  • Google Sheets: to read and update the user's own task list spreadsheet.
  • Course calendar link: a private calendar link the user provides, to read assignment due dates.

How data is used

  • Data is used only to show the user their own tasks and suggested replies.
  • Email is analyzed by an AI model running on the user's own computer. It is not sent to outside AI services.
  • Reply drafts are shown to the user only. Nothing is ever sent on the user's behalf.

What we never do

  • We do not sell, rent or share user data with anyone.
  • We do not use data for advertising.
  • We do not use data to train AI models.
  • No one other than the user can see the user's data.

Smart Task Manager's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Where data is stored

On the user's own computer and in the user's own Google account. Sign-in tokens are stored only on the user's computer.

Deleting your data

Remove access at any time at myaccount.google.com → Security → Third-party connections. Deleting your task sheet and the app's local folder removes everything.
